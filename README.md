# レッスンWON 公式サイト

京都府宇治市のペットホテル・犬のしつけ教室「レッスンWON」の公式サイトです。

**公開URL → https://lessonwon.jp**

---

## 概要

| | |
|---|---|
| 業種 | ペットホテル / ドッグトレーニング / 犬の幼稚園 / 一時預かり |
| 所在地 | 京都府宇治市広野町小根尾138-130 |
| 構成 | 静的サイト(フレームワークなし・ビルド不要) |
| ページ数 | 12ページ + 404 |

## 技術的な特徴

### 構成
- **素のHTML / CSS / JavaScript**。ビルドツール・パッケージ依存なし
- CSSは1ファイル、JSは1ファイルのみ
- ディレクトリ型URL(`/pet-hotel/` など)。将来ホスティングを変えてもURLが変わらない

### レスポンシブ
- **320px〜1600px** の全幅で横スクロールが発生しないことを実測で検証
- 料金表はスマホ幅でカード型に組み替え、横スクロールを排除
- ファーストビューは全画面サイズで1画面に収まるよう3段グリッドで制御

### 表現
- ページ間のワイプ遷移、肉球ロゴのローディング
- ファーストビューは文字マーキー + 写真バンド(上下逆方向)の多層構成
- `prefers-reduced-motion` に対応し、動きを抑える設定の環境ではアニメーションを停止

### SEO
- 構造化データ: `LocalBusiness` / `BreadcrumbList` / `FAQPage`
- 全ページに canonical / OGP / Twitter Card
- `sitemap.xml` / `robots.txt`
- 「宇治市 ペットホテル」「京都 犬のしつけ」等のローカル検索を想定したキーワード設計
- Google Search Console 登録済み / Google ビジネスプロフィール連携済み

### アクセシビリティ
- 見出し階層は各ページ h1 を1つに統一
- 装飾画像は `aria-hidden` と空 alt で読み上げ対象外に
- キーボード操作時のフォーカス表示を保持

```
├── dog-kindergarten/       犬の幼稚園

```

## 制作の進め方

要件定義・情報設計・SEOキーワード設計・デザイン方針の決定を行い、実装はAIコーディング(Claude Code)を用いて進めました。

事業者へのヒアリングをもとに料金・サービス内容を確定させ、独自ドメインの取得、DNS設定、公開、Google Search Console および Google ビジネスプロフィールへの登録まで一貫して対応しています。

## ライセンス

サイト内の文章・写真・ロゴはレッスンWONに帰属します。無断転載を禁じます。
